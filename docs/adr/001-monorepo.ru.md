# ADR 001: Хранить сервисы OrderFlow в monorepo

[English](001-monorepo.md) | [Русский](001-monorepo.ru.md)

Статус: принято. Дата: 2026-10-26.

## Контекст

OrderFlow начинается с одного сервиса заказов и развивается в систему взаимодействующих сервисов. Сейчас в репозитории один исполняемый файл. Организация репозитория должна допускать будущие сервисы без лишних затрат на сопровождение сейчас.

## Альтернативы

- Отдельный репозиторий для каждого сервиса: независимый доступ и настройки, но больше координации и повторяющегося сопровождения для небольшого проекта.
- Monorepo: связанные изменения, документация и инструменты находятся вместе, но границы сервисов нужно соблюдать явно.

## Решение

Хранить сервис заказов и будущие сервисы в репозитории OrderFlow. Начать только с сервиса заказов; остальные добавлять при конкретной необходимости. Сервис заказов отвечает за заказы, количества позиций и жизненный цикл; идентификаторы товаров и покупателей ссылаются на внешние данные.

Пока сохранить текущую структуру кода. Будущая раскладка `services/orders`, `services/catalog`, `services/customers` — пример, а не обязательство реализовать эти сервисы. Точные каталоги, границы Go-модулей и конфигурацию workspace выбрать при добавлении другого сервиса.

Сервисы должны независимо собираться, тестироваться и развёртываться. Взаимодействие — через явные контракты API или событий, без импорта внутренней бизнес-логики соседнего сервиса. Общие бизнес-модели ради переиспользования кода не вводим.

## Последствия

Связанные изменения можно проверять вместе, инструменты репозитория — переиспользовать. Общий репозиторий не требует совместного развёртывания и не отменяет совместимость контрактов. По мере роста потребуются проверки CI для отдельных сервисов и контроль зависимостей.

Это заменяет исходное направление модульного монолита на сервис заказов в будущей микросервисной системе. Сейчас не добавляем сервисы, не переносим код, не подключаем инфраструктуру и не выбираем границы Go-модулей. Проверка существования внешних ID остаётся вне первой версии.
